# Job Portal (Flutter Web Demo)

Live demo of an academic Flutter job portal app with Job Seeker, Recruiter and Admin roles, built with the VANTEX UI design system (Light/Dark mode, English/Urdu).

**Phase 4:** the app now runs on Firebase. Sign-in uses Firebase Authentication (email/password) and all data (jobs, applications, inbox, profiles, admin data) is stored in Cloud Firestore with role-based security rules, so changes persist and are shared between accounts.
